Connect WordPress forms to your Dash Dolphin account. Get SMS and email alerts on every form submission, with smart inquiry summaries and smart filtering.

== Description ==

Dash Dolphin sends an SMS and email the moment someone submits a form on your WordPress site, so you can respond before the lead goes cold.

Supported form plugins:

* Gravity Forms
* WPForms
* Contact Form 7
* Elementor Forms
* Fluent Forms
* Forminator
* Ninja Forms
* Formidable Forms

You will need a Dash Dolphin account at [dashdolphin.com](https://dashdolphin.com) and a personal API key to connect this plugin.

== Installation ==

1. Upload the plugin to the `/wp-content/plugins/` directory, or install through the WordPress plugin screen.
2. Activate the plugin through the Plugins screen.
3. Go to Settings: Dash Dolphin and paste your API key from app.dashdolphin.com.

== Frequently Asked Questions ==

= Do I need a Dash Dolphin account? =

Yes. Sign up at [dashdolphin.com](https://dashdolphin.com) before installing the plugin.

= Does this plugin send my form data to a third party? =

The plugin forwards form submissions to your Dash Dolphin account only. Nothing is sent until you connect a form with an API key.
